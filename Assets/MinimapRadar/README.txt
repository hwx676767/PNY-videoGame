Thank you for using MinimapRadar.

how to use :
Drag and drop "MinimapRadar" prefab (MinimapRadar/PREFABS/MinimapRadar) in a canvas in your scene.
Add the component "MRPlayer" to the object that is the center of your minimap (usually the player).
Add the component "MinimapItem" to the object you want to be displayed on the minimap.

That's all for the basic use.

To customize the items display on the minimap, you can drag and drop a sprite in the "DisplaySprite" box on the "MinimapItem" and "MRPlayer" components.
On theses components, you can also set the sprites color, their size, and their behavior on the minimap.
